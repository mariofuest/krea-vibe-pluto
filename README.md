# 🎮 Team Pluto: Vibecode Your Own Game

Das ist das Repository von **Team Pluto** beim Workshop „Vibecode Your Own Game: Von der Vision zum Release“.
Ihr seid Game Designer, Artists, Autor:innen und Sounddesigner:innen, eine KI übernimmt das Programmieren.

**Spielen:** https://mariofuest.github.io/krea-vibe-pluto/

**Alle Spiele, Ablauf und Assets:** https://github.com/mariofuest/krea-vibe

## So startet ihr

1. **Einladung annehmen:** Ihr bekommt eine Einladung zu diesem Repository per Mail oder unter https://github.com/mariofuest/krea-vibe-pluto/invitations.
2. **In VS Code öffnen:** Links auf das Symbol „Quellcodeverwaltung“ → „Repository klonen“ → `https://github.com/mariofuest/krea-vibe-pluto` einfügen, einen Ordner wählen, öffnen.
   Wenn VS Code fragt, ob es die empfohlenen Erweiterungen installieren soll: **Ja** (das ist „Live Server“).
3. **KI-Agenten starten** (Claude Code, Codex, Copilot, …) und loslegen, z. B.: *„Wir sind zu zweit und wollen ein Spiel machen, in dem …“*
   Um alles Technische kümmert er sich selbst, auch ums Speichern und darum, dass euer Team eure Änderungen bekommt.
4. **Spielen:** Rechtsklick auf `index.html` → **„Open with Live Server“**. Der Browser lädt nach jeder Änderung automatisch neu.

## KI-Schicht

Am Ende von Block 2 und Block 4 schreibt ihr mit eurem Agenten den `PLAN.md`. Dann startet **eine Person pro Team** einen Cloud-Agenten (Claude Code im Web, Codex Cloud oder Copilot-Agent) mit der Aufgabe:

> Arbeite `PLAN.md` ab, halte dich an `AGENTS.md`.

Danach könnt ihr den Laptop zuklappen. Zu Beginn des nächsten Blocks übernimmt euer Agent das Ergebnis.
